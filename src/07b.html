CLUSTERING

K-Means: Cara Kerja

  1. Tentukan jumlah cluster K.
  2. Pilih K titik sebagai centroid awal (acak).
  3. Tempatkan setiap titik ke cluster dengan centroid terdekat.
  4. Hitung ulang centroid = rata-rata titik di cluster itu.
  5. Ulangi langkah 3–4 sampai centroid tidak berubah signifikan.

Contoh: mengelompokkan pelanggan berdasarkan perilaku belanja agar strategi pemasaran bisa dibedakan per kelompok.

Iterasi K-Means (K = 3)
iterasi 0 — centroid acak
Centroid (belah ketupat putih) bergerak ke pusat massanya. Proses berhenti ketika penempatan titik tidak lagi berubah — artinya konvergen. Karena titik awal acak, hasil bisa berbeda antar-run; praktik umum: n_init=10.
Hierarchical Clustering: Dendrogram
agglomerative (bottom-up)
Setiap penggabungan terjadi pada ketinggian yang menyatakan jarak antar cluster. Memotong dendrogram pada ketinggian tertentu menghasilkan jumlah cluster yang diinginkan — tanpa harus menentukan K di awal.

Dua Arah Pembentukan

Agglomerative (bottom-up): mulai dari setiap titik sebagai cluster sendiri, gabungkan dua cluster paling mirip, ulangi sampai tersisa satu cluster besar.

Divisive (top-down): mulai dari seluruh data sebagai satu cluster, pecah berdasarkan perbedaan terbesar, ulangi sampai tiap titik terpisah.

Contoh: mengelompokkan dokumen teks berdasarkan kesamaan isi untuk membangun hierarki topik.
