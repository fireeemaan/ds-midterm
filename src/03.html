Dasar-Dasar Data Science:
Mengumpulkan Data

Mengumpulkan data adalah langkah awal yang menentukan kualitas seluruh proyek. Data yang dikumpulkan harus relevan, akurat, dan representatif terhadap masalah yang ingin diselesaikan. Salah di tahap ini, semua tahap berikutnya ikut salah — garbage in, garbage out.

Tiga Keluarga Sumber Data

🏢

Internal

Data yang dikumpulkan dan disimpan sendiri oleh organisasi. Sangat spesifik dan relevan dengan operasi.

  • Database perusahaan — penjualan, inventaris, data pelanggan (DBMS).
  • Log sistem — log server, aplikasi, transaksi.
  • Survei internal — wawasan karyawan & stakeholder.
🌐

Eksternal

Data dari luar organisasi; melengkapi data internal dan memberi perspektif lebih luas.

  • Data publik — sensus, cuaca, data ekonomi (pemerintah, non-profit, riset).
  • API — pengambilan otomatis (mis. OpenWeather, API media sosial).
  • Web scraping — mengekstrak data halaman web dengan program (mis. harga e-commerce).
📡

Lainnya

Sumber yang tidak selalu masuk dua kategori di atas, tetapi sering paling kaya.

  • Data sensor — IoT, sensor lingkungan, perangkat medis.
  • Data transaksi — kartu kredit, bank, e-commerce.
  • Data media sosial — posting, komentar, likes, shares.
Alur Data: dari Sumber ke Keputusan

Pola inilah yang membuat data mentah dari banyak sistem bisa dipakai bersama: ETL menyamakan format, data warehouse menyimpan versi terintegrasi, lalu analitik mengubahnya menjadi keputusan.

Proses Mengumpulkan Data

TAHAP 1

Identifikasi Kebutuhan Data

Tentukan apa yang ingin dicapai dan pertanyaan kunci yang harus dijawab, lalu jenis data yang diperlukan.

Kuantitatif: angka (luas rumah, harga). Kualitatif: deskriptif/kategori (jenis properti, lokasi).

TAHAP 2

Identifikasi Sumber Data

Petakan sumber internal, eksternal, dan lainnya. Nilai ketersediaan, biaya akses, dan reliabilitasnya.

TAHAP 3

Akses & Ekstraksi

Dapatkan izin akses, lalu ekstrak: query SQL, panggilan API (HTTP), atau web scraping (BeautifulSoup/Scrapy).

TAHAP 4

Pembersihan & Validasi

Periksa nilai hilang, duplikat, format tidak konsisten, dan nilai di luar rentang wajar sebelum data dipakai.

Mengapa Tahap Ini Penting?

  • Pengumpulan data harus direncanakan sebagai bagian dari langkah mencapai tujuan — bukan dikerjakan sambil jalan.
  • Hasilnya ikut menentukan desain proses data warehouse: skema, granularitas, dan jadwal pemuatan.
  • Kualitas data di hulu menentukan batas maksimum kualitas model di hilir.

Format Data yang Umum

  • File lokal — CSV, Excel, JSON, TXT.
  • Database — SQL (MySQL, PostgreSQL, SQLite).
  • API — REST API, web services.
  • Web scraping — mengambil data dari halaman web.
  • Real-time stream — data sensor, perangkat IoT.
  • Cloud storage — AWS S3, Google Drive, dan sejenisnya.

api_request.py
try:
    url = 'https://jsonplaceholder.typicode.com/users'
    response = requests.get(url, timeout=10)

    if response.status_code == 200:
        users = response.json()
        df_users = pd.DataFrame(users)
        print("Data berhasil diambil dari API")
        print(df_users[['id', 'name',
                            'email', 'phone']].head())
    else:
        print(f"Error: status {response.status_code}")

except Exception as e:
    print(f"Error saat mengambil data: {e}")
    print("Pastikan koneksi internet tersedia")

# Data sintetis untuk latihan / pengujian pipeline
np.random.seed(42)
n = 1000

synthetic = {
    'TransactionID': range(1, n + 1),
    'CustomerID': np.random.randint(1000, 5000, n),
    'ProductCategory': np.random.choice(
        ['Electronics', 'Fashion', 'Food',
         'Books', 'Sports'], n),
    'Amount': np.random.randint(50000, 5000000, n),
    'PaymentMethod': np.random.choice(
        ['Credit Card', 'Debit Card',
         'E-Wallet', 'Transfer'], n),
    'Rating': np.random.uniform(1, 5, n).round(1),
    'Date': pd.date_range(start='2024-01-01',
                          periods=n, freq='h')
}
df_synthetic = pd.DataFrame(synthetic)
print(df_synthetic.head(10))
Kesimpulan unit ini. Mengumpulkan data adalah langkah esensial yang melibatkan identifikasi kebutuhan, identifikasi sumber, akses & ekstraksi, serta pembersihan dan validasi. Memilih sumber yang tepat dan metode akses yang sesuai adalah prasyarat agar data yang terkumpul berkualitas tinggi dan relevan dengan tujuan analisis.
